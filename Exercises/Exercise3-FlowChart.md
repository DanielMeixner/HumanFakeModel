# Part 3: Agent Flow Chart - Visualizing the Workflow

In this section, you will use the Agent Flow Chart to examine the request workflow visually.

## Steps

1. **Open the Agent Flow Chart.**
   - In the Agent Debug Logs breadcrumb, return to the request overview.
   - Select the request you used in the previous part.
   - Select **Agent Flow Chart**.

2. **Examine the flow chart.**
   - Follow the boxes and arrows from the beginning of the request to the final response.
   - Find the stage where exploration of the local source code begins.
   - Identify which files the agent reads.
   - Find the stage where the follow-up questions for `/plan` are generated.
