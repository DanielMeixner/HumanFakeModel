# Preconditions

- Install [Visual Studio Code](https://code.visualstudio.com/).
- Install [Node.js 18 or newer](https://nodejs.org/) (npm is included).
- Run `npm install` in the repository root.

## Enable Agent Debug Logs

- Enable [`github.copilot.chat.agentDebugLog.fileLogging.enabled`](https://code.visualstudio.com/docs/agents/agent-troubleshooting/chat-debug-view#_agent-debug-log-panel) in VS Code settings.
